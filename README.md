## About this entry

A single-line roast of my own AI agent, aimed at one very specific habit: answering a completely different question than the one that was asked, and doing it with total, bullet-pointed confidence. The line lives as a constant in `main.ts`; running the program writes it, as UTF-8 text, to `entry.txt` in the output directory.

The entry line:

> My agent answered a question I never asked, confidently, in three bullet points with a summary — then asked if I wanted it as a PDF.

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `$OUTPUT_DIR` when that environment variable is set, and to `/output` otherwise.
